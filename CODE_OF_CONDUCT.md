# Code of Conduct — Classroom Use

InvenioLang is used by students worldwide. All participants agree to:

1. Respect classmates and teachers; no harassment or plagiarism.
2. Submit original `.inv` work unless group work is explicitly allowed.
3. Report vulnerabilities privately per `SECURITY.md:47`, never exploit shared lab machines.
4. Respect data privacy per `docs/PRIVACY.md`.

Enforcement: instructors may remove disruptive material and report abuse to
their institution. Contact: `tic@invenio.ac.cr`.
